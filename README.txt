วิธีใช้โฟลเดอร์ fb (ระบบหาสินค้าในกลุ่ม Facebook)
==================================================

โครงสร้าง
---------
fb\
  README.txt          <- ไฟล์นี้
  settings.txt        <- ค่าตั้งต้นรวม (อายุโพสต์สูงสุด, จำนวนโพสต์ที่ไล่ต่อกลุ่ม ฯลฯ)
  groups.txt          <- ลิงก์กลุ่ม Facebook ที่ให้ไปหา (1 บรรทัด 1 กลุ่ม)
  wanted\             <- สินค้าที่ต้องการหา (1 ไฟล์ = 1 สินค้า)
     _TEMPLATE.txt    <- แม่แบบ ก๊อปไฟล์นี้แล้วเปลี่ยนชื่อ
     example-rov.txt  <- ตัวอย่างที่กรอกแล้ว
  images\             <- รูปอ้างอิงสินค้า (โฟลเดอร์ย่อยชื่อเดียวกับไฟล์ใน wanted)
     example-rov\     <- รูปของ example-rov.txt
  results\            <- ผลลัพธ์ที่ Claude เขียนกลับมา (ไฟล์ .csv เปิดด้วย Excel ได้)

ขั้นตอน
-------
1. ใส่ลิงก์กลุ่มใน groups.txt
2. ก๊อป wanted\_TEMPLATE.txt เป็นไฟล์ใหม่ เช่น wanted\rov-skin-xxx.txt แล้วกรอก
3. (ถ้ามี) วางรูปอ้างอิงใน images\rov-skin-xxx\
4. เปิด Facebook ในเบราว์เซอร์ของแอป Claude ให้ล็อกอินไว้
5. สั่ง Claude ว่า "หาสินค้าจากโฟลเดอร์ fb"
   หรือระบุเฉพาะไฟล์ เช่น "หา rov-skin-xxx"
6. ผลจะอยู่ใน results\ชื่อสินค้า_วันที่.csv  -> เปิดลิงก์โพสต์แล้วทักผู้ขายเอง

กติกา
-----
- ไฟล์ที่ชื่อขึ้นต้นด้วย _ หรือมี  สถานะ: ปิด  จะถูกข้าม
- บรรทัดที่ขึ้นต้นด้วย # คือหมายเหตุ ไม่ถูกอ่าน
- Claude จะอ่านข้อความโพสต์ก่อน แล้วเปิดดูรูปเฉพาะโพสต์ที่ผ่านเงื่อนไขเบื้องต้น (ประหยัดโทเค็น)
- Claude ไม่ทักแชท ไม่คอมเมนต์ ไม่กดอะไรในโพสต์ ทำแค่อ่าน
