# ตัวอย่างที่กรอกแล้ว (ข้อมูลสมมติ) — ตั้ง สถานะ: ปิด ไว้ จะได้ไม่ถูกหาจริง

สถานะ: ปิด

== สินค้า ==
ชื่อสินค้า*: ไอดี ROV มีสกินหายาก
เกม*: ROV (Arena of Valor)
ประเภท: ไอดีเกม

คำค้น*: rov, ขายไอดี, ไอดี rov, id rov, รหัส rov

== เงื่อนไข ==
ต้องมี: ฮีโร่ครบ 100+, แรงก์ Conqueror ขึ้นไป
มีแล้วดี (ไม่บังคับ): สกิน SS, สกินลิมิเต็ด, เพชรเหลือ
ห้ามมี / ตัดทิ้งถ้าเจอ: ไอดีเช่า, ผูกเบอร์ถอดไม่ได้, โดนแบน
เงื่อนไขการโอนไอดี: เปลี่ยนอีเมลได้, ผ่านคนกลางได้

ราคาสูงสุด*: 2500
ราคาตลาดโดยประมาณ: 2000
